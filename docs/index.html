Rusty G6

A simple control panel for the Sound BlasterX G6 on Linux and Windows. Switch between speakers and headphones and tweak SBX effects, no command line needed.


        
      

      

      


      

        Prefer to download it yourself?
        Get the installers from GitHub
        (.deb, .rpm, AppImage, setup.exe, MSI).
      

    


    

      
What it does

      
    
        
  • Switch the G6 output between speakers and headphones
    • 
        
  • Adjust SBX effects: Surround, Crystalizer, Bass, Smart Volume and Dialog Plus
    • 
        
  • Works on Linux, where Creative doesn't provide an app, and on Windows
